# Auto2dLabel v0.1 里程碑定义

> v0.1 = 自然语言驱动的 Agentic 2D 图像自动标注，无需记忆 CLI 参数。

---

## 一、v0.1 的核心主张

**用户只需要说一段话，系统完成所有标注。**

```txt
"帮我检测 /data/coco_val/ 下的所有图片，
 IoU 和 confidence 都设为 0.5，
 只检测汽车和行人，用 faster rcnn v2"
```

不需要 `-t 0.5 --iou 0.5 -d fasterrcnn_resnet50_fpn_v2`。

---

## 二、v0.1 功能清单

### F1: 自然语言参数提取 ✅ 已有基础

**输入**：用户的一段话（可含路径、类别、阈值、模型、多任务指令）。

**LLM 做的事**：

- 从文本中提取：数据路径、检测类别、置信度阈值、IoU 阈值、模型选择
- 中英类别名自动映射（"汽车"→"car"、"行人"→"person"）
- 未指定的参数采用默认值

**验收标准**：用户说"检测汽车和行人，conf=0.5"，系统自动设置 `prompts=["car","person"]`、`threshold=0.5`，无需任何 CLI flag。

### F2: 缺失参数交互追问 🆕

**触发条件**：LLM 解析用户指令后，发现必需参数缺失或模糊。

**交互流程**：

```txt
用户: "帮我标注数据集A"
Agent: "需要确认几点：
      1. 检测哪些类别？（如 car, person, bicycle）
      2. 置信度阈值用默认的 0.3 吗？
      3. 用默认模型 faster-rcnn-v2 吗？
      30 秒内无回复将按默认值继续。"

[等待 30 秒]

用户未回复 → 按默认值执行
用户回复 "汽车和行人" → 补充参数，继续执行
```

**实现要点**：

- 等待时长可配置（默认 30 秒），也支持 `--confirm-timeout 10` 或 `--no-wait`（跳过确认直接执行）
- 追问仅针对**缺失信息**，已明确的部分不重复提问
- 追问消息格式清晰，用户可直接回复关键词

### F3: 多任务编排 🆕

**输入示例**：

```txt
"先对 /data/dataset_A/ 做目标检测，只检测汽车，conf=0.5，用 yolov8；
 再对 /data/dataset_B/ 做目标检测，只检测行人，conf=0.3，用 faster-rcnn-v2"
```

**LLM 做的事**：

- 解析为两步任务计划（TaskPlan）
- 每步任务包含完整的独立参数（path, prompts, threshold, iou, model）
- 生成执行计划概要，展示给用户确认

**确认流程**：

```txt
Agent: "我理解你的任务如下：
      Step 1: 目标检测 → /data/dataset_A/ → 汽车 → conf=0.5 → yolov8n.pt
      Step 2: 目标检测 → /data/dataset_B/ → 行人 → conf=0.3 → fasterrcnn_resnet50_fpn_v2
      共 2 步。30 秒后自动执行。"

[等待 30 秒]

用户未回复 → 按计划执行
用户 "确认" → 立即执行
用户 "第二步 conf 改成 0.4" → 修改后重新展示确认
```

**验收标准**：支持 2+ 步顺序执行的工作流，每步独立参数、独立输出。

### F4: 代码级质量评估 ✅ 已实现

> 2026-08-16 补做：`agent/evaluate.py` 实现 0 框降阈值重试（×1）、类别覆盖率检查、>200 框异常警告、全低置信度标记，LLM / chat / no-LLM 三路径共用。剩余 LLM 自主决策的 Evaluate 节点归入 M3，见 `AutoLabel_plan.md`「已知缺口」。

**不依赖 LLM 做评估**。所有质量判据在代码中实现：

| 判据 | 实现 | 行为 |
| --- | --- | --- |
| 0 框检出 | `len(bboxes) == 0` | 降阈值重试、或报告用户"该图可能不含目标类别" |
| 类别覆盖率不足 | 要求 N 类只检出 < N 类 | 报告用户"部分类别未检出，建议检查 prompt 或换模型" |
| 全部低置信度 | 所有框 conf < τ_low | 标记为困难样本，建议人工标注 |
| >200 框 | 框数异常多 | 建议用户提高阈值或检查图像内容 |

### F5: HITL 置信度三分流 ✅ 已完成

- `conf >= 0.7` → 直接采纳，进正式 COCO/YOLO/VOC 导出
- `0.3 <= conf < 0.7` → 写入 `*_review.json` 人工复核队列
- `conf < 0.3` → 写入 `*_hard.json` 困难样本

阈值可通过自然语言指令调整（"低置信度阈值设为 0.4"）。

### F6: 日志与可复现性 ✅ 已完成

- JSON 结构化日志（method / timestamp / model / params / steps / result）
- 日志、可视化 PNG、导出 JSON 共享同一时间戳
- 支持 `log_python_api_call` 和 `log_llm_call` 两种 method

### F7: 多格式导出 + Round-trip 验证 ✅ 已完成

- COCO JSON / YOLO txt / Pascal VOC XML
- Round-trip 测试全部通过（`pytest auto2dlabel/tests/`）

### F8: 模型引擎 ✅ 已完成

- 3 引擎 × 47 模型；`--no-llm` 对照能力于 2026-08 重构迁至 `auto2dlabel/tests/helpers/no_llm_baseline.py`（CLI flag 已移除）
- 权重统一管理至 `auto2dlabel/weights/`

### F9: Benchmark 测试 ✅ 已完成

- VOC 2007 benchmark 脚本（`auto2dlabel/benchmarks/voc_benchmark.py`）
- 支持 tqdm 进度条、`--max-images` 快速测试、`--model` / `--conf` 参数化
- 输出 JSON + Markdown 报告至 `benchmarks_outputs/`

实测数据与结论见 `tests/test-v0.1.md`。
