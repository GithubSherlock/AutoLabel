## Phase 1: 实例分割 ✅

### 四种分割模型

| 模型 | 引擎 | 权重 | 特点 |
| --- | --- | --- | --- |
| **SAM/SAM2** | Ultralytics | 自动下载 ~160MB | bbox prompt → mask，1s，轻量 |
| **SAM3** | Ultralytics (Meta) | 手动下载 ~3.4GB | 文本 prompt → 检测+分割一步，开放词汇，**最强** |
| **Mask R-CNN** | torchvision | 自动下载 | COCO 预训练，检测+分割一步，2.5s |
| **FastSAM** | Ultralytics | 自动下载 ~140MB | bbox IoU 匹配，1.1s，最轻量 |

实测对比与最佳实践见 `tests/test-v0.2.md`。

### CLI 使用

```bash
# SAM3 文本驱动（自带检测，无需指定检测模型）
auto2dlabel chat "检测并分割 000860.png 中的汽车和行人，用 sam3" --no-wait

# SAM bbox prompt（先检测后分割）
auto2dlabel chat "检测并分割 000860.png 中的汽车" --no-wait  # 默认 fastsam

# Mask R-CNN 一步完成
auto2dlabel chat "检测并分割 000860.png 中的汽车和行人，用 maskrcnn" --no-wait
```

## Phase 2: 类别自动推荐 ✅

### 流程

```txt
用户: "帮我推荐 000860.png 中应该标注哪些类别"
  → COCO 80 类全扫描 → 统计每类 count × avg_conf
    → Agent 建议: ✅ car(检出多, 置信高), ✅ person
    → 用户确认/修改 → 正式标注
```

### 核心模块

- `tools/recommend.py` — `scan_classes()` / `recommend_classes()` / `format_recommendation()`
- 推荐算法: `count × avg_conf` 排序，过滤 <3 检出 + <30% 置信度的类别
- 集成在 `chat` 命令中，当 TaskPlan prompts 为空时自动触发

## Phase 3: Web 审核界面 ✅

### 架构

```txt
auto2dlabel/web/
├── server.py          # FastAPI 后端，POST /annotate
└── static/
    └── index.html     # Canvas 前端，上传→标注→审核→下载
```

### 功能

- 上传图像 → 输入自然语言指令 → 选择模型/阈值 → 开始标注
- Canvas 实时显示 bbox + 标签 + 置信度，彩色边框按类别区分
- 点击右侧列表中的框 → 标记删除（划线），再点恢复
- 勾选「分割」→ 同步生成 mask 叠加到 Canvas（v0.3 周期补齐，附 bbox_index 对齐；COCO 导出改走后端 `/api/export-coco`）
- 一键下载 COCO JSON（自动过滤已删除的框）

### 启动

```bash
python3 -m auto2dlabel.web.server
# → http://localhost:8765
```
