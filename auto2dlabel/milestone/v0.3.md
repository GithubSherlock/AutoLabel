## Phase 1: 图像分类（CLIP / SigLIP）✅

### 模型

| 模型 | 引擎 | 权重 | 特点 |
| --- | --- | --- | --- |
| **CLIP** | transformers | openai/clip-vit-base-patch32 | 图像-文本余弦相似度 → 候选标签 softmax 概率 |
| **SigLIP** | transformers | google/siglip-base-patch16-224 | 原生 sigmoid logits，多候选按 softmax 归一化排序（与 CLIP 语义一致） |

- 懒加载红线：构造不触发下载；`_load()` 幂等；权重下载到 `auto2dlabel/weights/hf/`（HF_HOME 统一管理，顺带修复 GroundingDINOModel 未设 HF_HOME 的存量债）
- 结果落在 `Annotation.labels: list[ImageLabel{label, score}]`（**不是** metadata）；模型名存 `metadata["model"]`

### CLI 使用

```bash
auto2dlabel chat "把 000860.png 分类为猫和狗，用 clip" --no-wait
# → outputs/000860.json（每图一个 JSON：image_path/width/height/model/labels）
```

### 导出

`export/cls.py`（format="cls"，目录型，每图 {stem}.json；score 保留原始浮点精度）

## Phase 2: OBB 旋转框（YOLO-OBB）✅

### OBB 模型

`yolo11n/s/m/l/x-obb.pt` 5 枚（Ultralytics），`create_obb_model()` 按文件名分发。

### 角度约定（设计红线）

- `Bbox.angle`：弧度，width 轴相对 x 轴，取值 (-π/2, π/2]，与 ultralytics xywhr **零转换**；HBB 恒为 0
- `to_dict()` **恒输出** angle；穿透点四处：to_dict / state._annotation_from_dict / export._make_bbox / visualize——漏一处静默丢角，OBB roundtrip 测试兜底（1e-6）

### OBB 导出

| 格式 | 内容 |
| --- | --- |
| `dota` | 每图 txt `class_id x1 y1 x2 y2 x3 y3 x4 y4 0`（角点 = center + R(angle)·(±w/2,±h/2)，atan2 顺时针排序）+ classes.txt |
| `yolo_obb` | 每图 txt `cls cx cy w h angle`（弧度；angle=0 时与 export_yolo 前 5 token 一致） |

可视化：`angle ≠ 0` 时画旋转多边形（cv2.polylines），HBB 仍走矩形。

### OBB CLI 使用

```bash
auto2dlabel chat "检测 000860.png 中的旋转车辆，用 yolo11n-obb.pt" --no-wait
# → dota/yolo_obb 导出 + 可视化 + HITL 三档分流照旧
```

## Phase 4: M2 / M3 闭环补全 ✅（本期同期）

### M2 Web 闭环

- mask 叠加：`/api/annotate` 响应 mask 附 `bbox_index`，前端 Canvas `drawMasks` 半透明填充 + 「显示 mask」开关
- 复核队列消费方：`GET /api/review-files` / `GET /api/review-image`（图片后缀白名单）/ `POST /api/review-save`（过滤 → COCO 写入 → 源文件加 `.reviewed` 后缀）；前端「标注 / 复核队列」模式切换
- 顺手修：前端 `downloadJSON` 改走 `POST /api/export-coco`（复用 `build_coco_dict` 纯函数，修 image_path 恒为 upload.jpg 的 bug，删手写 builder）

### M3 Agentic 闭环

- **LLM Evaluate 节点**：`quality.ok == False` 时才附加 evaluate_quality 工具（正常图零 token）；不进全局 registry（防跨图污染）；LLM 只选动作 accept / flag_for_review / retry_lower_threshold，代码执行（retry = conf×0.25 每图一次；flag 写 metadata，triage 代码层并入 review 档）；迭代核算 iter1 detect → iter2 evaluate → iter3 总结 ≤3 红线守住
- **batch 失败隔离 + --resume**：单图失败不再中断整批；`--resume <清单>` 跳过 ok 重跑 failed；每图成功写 `{stem}_{ts}_state.json` 快照
- **主动学习采样**：`auto2dlabel sample --top-k 5` 聚合 `outputs/*_review.json`（已含 hard 档），score = mean(1−2|conf−0.5|) + 0.1×类别数，确定性 top-K 清单

## 取舍注记（如实记录）

- **angle 约定**：弧度、(-π/2, π/2]、width 轴相对 x 轴——与 ultralytics xywhr 零转换，DOTA 导出时由角点公式换算；HBB 恒 0
- **采样只聚合 review 队列**：`sample` 仅读 `*_review.json`，不做训练闭环
- **AgentState 半接线**：to_dict 已用于 batch 每图快照；from_dict 恢复不实现（快照供人查/脚本消费）
- **rotate 评测 P1/P2**：P1 合成自测完成；P2 DOTA Task1 挂起（GT 未验证到）
- **Oriented R-CNN 延后**：mmrotate 依赖重，v0.3 只做 YOLO-OBB
- **Web 后续项**：bbox 拖拽/标签编辑、分类与 OBB 结果的 Web 展示列入后续
