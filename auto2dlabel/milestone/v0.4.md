# Auto2dLabel v0.4 里程碑定义

> v0.4 = 姿态估计：ViTPose / RTMPose 关键点检测 + COCO keypoints 导出。

v0.4 状态：📋 未动工（2026-08-17 立项；排期见 `docs/AutoLabel_plan.md` 下一步——与 Auto3dLabel 路线无依赖，穿插/殿后）

---

## Phase 1: 模型接入 📋

- **RTMPose**（rtmpose-s/m/l，COCO 17 关键点，Ultralytics 生态一致、轻量）优先；**ViTPose**（精度档）备选
- 输出：每人 17 关键点 (x,y,conf) + 人 bbox + 骨架连接
- **红线**：模型输出关键点索引 ≠ COCO 17 点顺序时显式映射（不靠隐式对齐）

## Phase 2: 数据流 + 导出 📋

- Annotation 扩展：关键点挂 bbox（per-instance），序列化走 to_dict/_annotation_from_dict（沿用 OBB 角度约定的「穿透点四处」教训：漏一处静默丢关键点）
- 导出：COCO keypoints 格式（`[x,y,v]` + `num_keypoints`）+ YOLO-pose 格式（`export/` 新格式，round-trip 测试）

## Phase 3: 闭环 + 评测 📋

- 质量评估：低置信关键点占比 / 检出人数异常 → 复用 `agent/evaluate.py` 判据模式，入 HITL 三档（整人置信度分流）
- Benchmark：COCO keypoints（AP / OKS 指标）小样本冒烟，按 `docs/Benchmark_plan.md` 程序规范（10.1–10.8）
- Web 审核：关键点骨架叠加显示（后续版本可合并到「分类与 OBB 展示」缺口一起做）
