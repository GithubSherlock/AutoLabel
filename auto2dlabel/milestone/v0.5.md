## 规划内容

### 1. Pose 姿态估计

- ViTPose/RTMPose + COCO keypoints 导出（关键点挂 bbox 数据流，YOLO-pose 可先行）
- 原 v0.4「Pose 版」定义整体平移至此；与 3D 无依赖，殿后

### 2. 指代检测 L2（Florence-2 兜底）

- **触发**：v0.4 约束过滤层 L1（文本解析 + CLIP 属性 + 代码方位）解析不出/过滤失败时兜底——关系/复合指代（「红车旁边的行人」「第二辆车后面的人」）
- **形态**：Florence-2-base 0.23B（~1G）/ large 0.77B（~2.4G），任务词条架构（非聊天模型，微软统一视觉基础模型）
- **成本**：CPU 单图 5-30s——低频使用（序列级一次指代识别），不做逐帧
- **架构**：插入 v0.4 3a 过滤链的「属性/关系判断」环节，输出结构化约束或直接出框

### 3. 指代检测 L3（Qwen2-VL-7B）

- 复杂上下文指代（「第二辆车后面穿红衣服的人」）——L2 也覆盖不了的复合场景
- Q4 量化 ~4.5G 权重；CPU 分钟级不可用 → **GPU 到位后**低频关键帧（视频序列级一次指代识别）
- 与 L2 的关系：同一调用点，按能力/成本阶梯升级

### 4. 自动车道 ROI（v0.4 C2）

- 车道线模型（YOLOP/Ultra-Fast-LODA）或 VLM 看图生成车道多边形 → 空间约束自动输入
- **复用 v0.4 3a 空间过滤实现**（ROI 多边形是输入方式差异，过滤链零改动）
- 依赖 v0.4 约束过滤层先落地

### 5. 分类数据集扩展

- ILSVRC2012 val 接入（ImageNet100 已闭环）

### 6. Web 交互增强

- bbox 拖拽/标签编辑、分类与 OBB 展示 ✅ 已随 v0.4 Phase 3 消化（2026-08-22，实测见 `tests/test-v0.4.md` §M）
- **CVAT 借鉴复核增强 ✅ 2026-08-23**（P0+P1+P2 全量，实测见 `tests/test-v0.5.md` Web 节）：未保存确认（切换模式/加载文件/beforeunload）+ 保存态反馈；快捷键 Tab/Shift+Tab 循环选中居中、Del 删除、Ctrl+Z/Ctrl+Shift+Z undo/redo（闭包栈 MAX 32）、Ctrl+S、Esc 三态、N 画 issue；8 点缩放 + OBB 旋转手柄（旋转系对角固定数学）；对象列表升级（色块/标签下拉/隐藏/锁定/删除图标/hover 高亮/排序/计数）；置信度过滤滑条；右键菜单（改标签/删除/锁定/置顶/置底）；区域 issue 系统（框选→输入→半透明浮层→解决/重开→落盘）；**edited_by_human 每框人工修正标记**（四操作置位，落盘 `*_reviewed.json` 形成「AI 初稿→人工修正」数据回路）；已复核文件重开复查（review-files `reviewed` 列表 + COCO 归一化重读 + 原地覆盖）；前端拆分为 `index.html`（CSS+DOM）+ `static/app.js`（模块化注释分区，仍无构建链）
