# Auto3dLabel v0.1 里程碑定义

> v0.1 = 3D 标注 MVP：单帧点云 + 相机图像 → 2D 基础模型 → 3D bbox 初稿（路线 2「2D → 3D 提升」）。面向物理 AI / 自动驾驶：3D bbox 是自动驾驶标注价值栈的第一层（→ 跟踪 ID/运动属性 → BEV/占用 → HD 地图）。

v0.1 状态：📋 未动工（2026-08-17 立项；**2026-08-19 战略调整：主推进**——Auto2dLabel 为基石、Auto3dLabel 优先；与 Auto2dLabel v0.4 双线并行。调研与路线论证见 `docs/AutoLabel_plan.md` Auto3dLabel 部分）

> **核心决策**：MVP 复用 Auto2dLabel 已交付的 G-DINO + SAM2 2D 能力与 Agentic/HITL 骨架，**零新增模型**；新增代码只有「点云加载 → 反投影 → 聚类 → bbox 拟合 → 导出」五步。不引入 3D 检测模型（路线 1 依赖），不碰 3DGS（路线 3，远期）。

> **数据已就位（2026-08-19）**：KITTI object（3D 检测基准，正确版本）位于 `Documents/datasets/KITTI/object`——原目录仅 image_2 部分 + label_2 全量，已从 `/autodl-pub/data/KITTI/object` 补齐 velodyne（点云）/calib（标定）/image_2 全量 7481 训练帧 + testing。

> **版本路线（显式化）**：v0.1 单帧 3D bbox → v0.2 多帧 + 跟踪 ID/运动属性（依赖 Auto2dLabel v0.4 Tracking）→ v0.3+ BEV/占用与重建路线评估。每一版都有自动驾驶价值增量。

## Phase 1: 数据与标定加载 📋

- **KITTI**：velodyne `.bin`（x,y,z,intensity）×4 float32 + `calib_*.txt`（P2 / R0_rect / Tr_velo_to_cam 投影链）
- **nuScenes**：单帧 sample → 多相机图像（CAM_FRONT 起步）+ LIDAR_TOP 点云 + calibrated_sensor / ego_pose
- 内部统一：点云存 LiDAR 系；相机内参 K + 外参 T 组成投影链（点云 → 图像）
- **红线**：标定链任何一环错 → 投影全错且难察觉；必须做「点云投影回图像散点图」自检

## Phase 2: 2D mask → 语义点云 📋

- 复用 auto2dlabel：G-DINO 开放词汇 bbox（或 YOLO 检测）→ SAM2 box-prompt mask；分类标签随 mask 传递
- 反投影：图像 mask 内的 LiDAR 点 = 该类别语义点云（只取 LiDAR 实际观测到的点）
- 多相机融合：各相机独立检测 → 各自反投影 → 同类别点合并（v0.1 可先单相机跑通再融合）
- **红线**：反投影用 **mask 不用 bbox**——bbox 边缘会把背景点投进来，SAM mask 才是像素级边界

## Phase 3: 聚类 + 3D bbox 拟合 📋

- DBSCAN 实例聚类（eps 按距离/量级自适应，min_samples 视点密度）
- 鸟瞰 (x,y) `cv2.minAreaRect` → 中心/尺寸/yaw；高度 z 取分位区间（剔除噪点）
- 多视角投票：同一实例多相机重复检出 → 重投影 IoU 融合（v0.1 单相机可跳过）
- **红线**：遮挡/截断目标点稀疏 → 拟合退化；输出「拟合点数」量化置信度，供 HITL 分流（宁缺勿假）

## Phase 4: 导出 + 评测 + 闭环 📋

- **导出**：KITTI label（Car/Pedestrian/Cyclist 类映射，rotation_y 相机系）/ nuScenes `sample_annotation` 表
- **评测**：3D IoU / BEV IoU 对 GT 冒烟（KITTI difficulty 分层）；benchmark 脚本按 `docs/Benchmark_plan.md` 程序规范接入
- **HITL 复用**：三档分流 + 可视化（BEV 散点 + 3D bbox 俯视图）
- **Agentic 复用**：自然语言「标注这帧中的汽车和行人」→ planner → 上述流水线（复用 auto2dlabel 编排骨架，3D 新代码只放 auto3dlabel/）

## 模型/依赖汇总（v0.1）

- **模型零新增**：复用 auto2dlabel 84 模型目录（G-DINO + SAM2/SAM3 + YOLO）
- **新增依赖**：numpy/scipy（DBSCAN）、cv2（minAreaRect）、可选 open3d（可视化）；nuscenes-devkit 仅作 GT/标定解析（或纯 numpy 解析，避免重依赖）
- **数据**：KITTI / nuScenes mini（数据与权重不入库，同 2D 红线）
