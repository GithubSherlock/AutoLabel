# Auto3dLabel v0.2 里程碑定义

> v0.2 = LiDAR 3D 检测器精度（P1）+ 多帧跟踪 ID/运动属性（P2）+ nuScenes 支持（P3）。
> 立项 2026-08-26（用户决策：三 Phase 全上 / 硬装 mmdet3d 全套 / 双引擎路由）；**本版不 commit**。

## 背景与决策

v0.1 反投影拟合路线 20 帧实测 3D AP 近零（Car easy 0.0 / Ped easy 2.3），是精度天花板实证。v0.2 引入 LiDAR 系 3D 检测模型（唯一可达标注业务精度的路线：KITTI car moderate AP3D 74–81）并补齐原定义的多帧能力。

三项锁定决策（2026-08-26 AskUserQuestion）：
1. **范围**：三 Phase 全上（P1 精度 → P2 多帧跟踪 → P3 nuScenes）
2. **模型路线**：硬装 mmdet3d 全套（mmcv 2.1.0 源码编译，CUDA 13 工具链踩坑已通）
3. **引擎策略**：双引擎路由——LiDAR 直检为主引擎（`-d pointpillars_kitti`），v0.1 反投影链保留为开放词汇回退引擎（默认 2D 路径零改动），评测分列

## Phase 1：LiDAR 3D 检测器（mmdet3d 硬装）

- 新建 `models/detection3d.py`：Det3DResult / Detector3D Protocol / Mmdet3dDetector（零加载 __init__ + 幂等 _load + ImportError 守卫）/ create_detector3d 工厂
- 双引擎路由：`tools/pipeline.annotate_frame` 增 `det3d` 参数（非 None → LiDAR 直检，跳过 2D 整链）；`cli._make_models` 双引擎工厂；tools3d/planner3d 模型名映射
- fit_points 替代 = 3D 框内 LiDAR 点计数（`geometry.points_in_box`）→ triage_3d/HITL/Web 零改动
- 评测双口径：现有 `kitti3d_benchmark.py`（11-point + IoU 0.5，v0.1 基线对比）不变；新建 `kitti_official_ap.py`（官方 40-point + 每类 IoU {Car:0.7, Ped:0.5, Cyc:0.5}，与模型 zoo 对表口径）
- **P1 验收**：官方口径 20 帧 Car moderate AP3D ≥ 74（zoo 发布值 77.6）；全 val 3769 帧终版数字 + zoo 对照表

## Phase 2：多帧跟踪 ID / 运动属性

- 新建 `tools/track3d.py`：Tracker3D（BEV IoU + 匈牙利匹配 + 恒速 Kalman；missed > max_age 删除）；3D 侧自写（BEV IoU 直接可算，2D 级联不引入）
- CLI：`auto3dlabel run 003712-003731 "检测汽车" -d pointpillars_kitti --track3d` → 每帧 label + 全局 tracks.json（track_id/帧列表/速度历史）
- `Box3D.track_id` 可选字段（穿透点清单第 7 条：to_dict 非 None 输出 → Web/复核队列自动穿透）；KITTI label 15 字段纯净零改动
- **P2 验收**：合成序列 3 目标 10 帧 ID 一致性 100%（test_track3d 8 用例）；KITTI 20 帧真权重冒烟（IDSW/轨迹长/velocity vs GT 差分 MSE）

## Phase 3：nuScenes（Mini 口径）

**数据策略（2026-08-27 实测修正）**：原计划「Trainval 10 卷 blob 流式选择性物化 ~3.5G」→ 改用 AutoDL 公共盘现成 Mini 单卷（`/autodl-pub/data/nuScenes/Fulldatasetv1.0/Mini/v1.0-mini.tgz` 3.9G）解压为标准 dataroot（`Documents/datasets/nuscenes_mini`），流式物化脚本整条删除（Occam）。

- 新建 `data/nuscenes.py`（devkit 懒加载守卫 + val 场景枚举 + GT→NusBox 原始表直映射）、`schema/nuscenes_box.py`（NusBox 全局系 + 四元数，不共用 Box3D）、`configs/nuscenes.py`（官方 10 类 + 口径常量）
- `tools/geometry.yaw_to_quat / quat_to_yaw`（唯一转换点）；`export/nuscenes_json.py`（官方提交 JSON + 自检）；`benchmarks/nuscenes_benchmark.py`（简化 x-y 旋转矩形 IoU 评测，口径差异如实记录）
- **P3 验收**：Mini val 2 场景 pointpillars_nus 简化评测出表（mAP 对照 zoo 44.6 仅参考——口径/规模不同）+ 提交 JSON 自检通过；centerpoint_nus 为 gated 升级项

## 安装策略（已执行）

- M0：cu13 nvcc 工具链（conda nvidia 频道，CUDA_HOME=targets/x86_64-linux；cicc/ptxas 子工具 ln + PATH 修复——编译必须 `PATH=$CUDA_HOME/bin`，nvcc 子工具经 sh 查找 PATH 而非自身目录）
- M1：`pip install mmcv==2.1.0 --no-deps --no-cache-dir`（**--no-deps 红线**：防 numpy 升 2.2.6 破坏 ABI）+ `mmdet3d==1.4.0 --no-deps` + configs sparse-checkout（v1.4.0 主线）
- 权重：`weights/download_detector3d.sh`（openmmlab 直链，URL 取自 metafile.yml）
